# 🌿 Slim Chá Oficial & IArmonize – Página de Vendas de Alta Conversão

Página oficial de vendas responsiva com links de checkout direto para afiliados da Braip, pronta para subir no **GitHub** e publicar na **Vercel** sem nenhuma chave de API ou banco de dados externo.

---

## ⚡ Destaques do Projeto

- 🎯 **100% Direto ao Ponto:** Botões com link de afiliado direto para o checkout na Braip.
- 📱 **Totalmente Responsivo:** Perfeita adaptação para celulares, tablets e telas grandes.
- ⚡ **Zero Chaves de API:** Funciona diretamente sem dependências de servidores ou bancos externos.
- 🔄 **Preservação de UTMs:** Parâmetros de anúncios (Facebook, Instagram, Google Ads) são repassados automaticamente para o checkout.
- ⚙️ **Painel de Afiliado Integrado:** Permite testar ou alterar links de afiliado direto pela interface do site.

---

## 🚀 Como Rodar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de teste
npm run dev

# Compilar para produção
npm run build
```
